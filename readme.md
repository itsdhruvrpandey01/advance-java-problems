# 🚀 Advanced Java Problems

A collection of **real-world Java problems** focused on backend concepts like caching, concurrency, and system design.

---

## 📌 Overview

This repository focuses on building **strong core Java skills** by implementing practical problems such as:

* LRU Cache
* Rate Limiter
* Thread-safe structures
* Backend-oriented logic

---

## 🧠 Topics Covered

* Data Structures (advanced usage)
* Multithreading & Concurrency
* Caching Techniques
* Backend Design Patterns

---

## ⚙️ Tech Stack

* Java 8+
* Core Java (Collections, Concurrency)

---

## 🛠️ Run Locally

```bash
git clone https://github.com/itsdhruvrpandey01/advance-java-problems.git
cd advance-java-problems
javac Main.java
java Main
```
